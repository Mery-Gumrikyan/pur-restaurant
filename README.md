# Pur Restaurant Website

A responsive restaurant website built with React and Vite for Pur Family Restaurant in Tsaghkadzor, Armenia.

## About the Project

This project is a frontend portfolio website created to practice and demonstrate modern frontend development fundamentals.

It includes a restaurant menu, photo gallery, restaurant history, location, contact information, and social media links.

## Features

- Responsive design for desktop, tablet, and mobile
- Mobile navigation menu
- Restaurant dishes section
- Responsive photo gallery
- Auto-rotating history carousel
- Google Maps location link
- Phone and email contact links
- Social media links
- Smooth section navigation
- Accessible and semantic HTML elements

## Technologies

- React
- JavaScript (ES6+)
- HTML5
- CSS3
- React Router
- Vite
- ESLint
